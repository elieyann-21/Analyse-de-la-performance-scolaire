# Analyse-de-la-performance-scolaire
Dans le cadre de la seconde évaluation de Akieny Academy, nous nous sommes proposé dans réalisé une analyse de données afin de mettre en pratique sur un projet concret les notions apprises.
La thématique choisie a porté sur l’éducation plus précisément la réussite scolaire à partir d’une base de données obtenue sur Kaggle.
       
       Notre question de recherche était :
Quels sont les facteurs associés à la réussite scolaire des élèves

Notre objectif était :
Identifier les facteurs explicatifs de la réussite scolaire
